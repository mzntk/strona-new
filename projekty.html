Barbie Brand Visualization

Final project for Data Visualization

Python Pandas Matplotlib Seaborn Jupyter Notebook Link to GitHub repository

An analytical project examining 65 years of the Barbie brand's history, Mattel's business transformation, and the "Barbenheimer" phenomenon. It shows that Barbie is a powerful, global data empire.

  • Financial History: Analysis of stock market ups and downs, the 1998-2000 crash, and the 2014 peak.
  • Universe Demographics: Character structure in animations proving the dominance of female agency.
  • Trends and Anomalies: Spikes in popularity on Google Trends.
  • Barbenheimer Effect: Impact of the 2023 premiere on box office results and historical disruption of seasonality.

Analysis of Pit Stop Strategies in Formula 1

Data Analysis Laboratory / Mathematical Modeling and Data Analysis MFI UG

R caret rpart ggplot2 dplyr Machine Learning Link to GitHub repository

Building and comparing machine learning models predicting an F1 driver's decision to pit on the next lap, based on tire parameters, times, and race progress.

  • Logistic Regression: The weakest model (Sensitivity 14.4%, F1=0.22) – the linear boundary struggles with non-linear phenomena on the track.
  • Decision Tree: Compromise model (Sensitivity 41.2%, F1=0.48) – a dilemma between interpretability and predictive power.
  • k-Nearest Neighbors (KNN): The winner (Sensitivity 67.6%, F1=0.741, Balanced Accuracy >81%) – an outclassing model, perfectly handling the grouping of similar racing moments.
