# 👩‍💻 Maja Zontek – Portfolio Internetowe

Kod źródłowy mojego osobistego portfolio w HTML i CSS. Strona to cyfrowa wizytówka, która udowadnia, że twarda analityka danych świetnie łączy się z umiejętnościami miękkimi i zarządzaniem. Prezentuje moje doświadczenie zawodowe, projekty Machine Learning oraz aktywną działalność studencką.

🌐 **[Zobacz stronę na żywo](https://mzntk.github.io/strona-new)** *(pamiętaj o podmianie linku po wdrożeniu na GitHub Pages!)*

## 🛠 Technologie

Strona została napisana od zera, bez użycia zewnętrznych frameworków, aby zachować lekkość i pełną kontrolę nad kodem.

*   **HTML5** (Semantyczna struktura)
*   **CSS3** (Flexbox, CSS Grid, zmienne CSS, płynne animacje i przejścia)
*   **GitHub Pages** (Hosting)
*   **Typografia:** DM Sans (Google Fonts)

## 📂 Struktura witryny

Projekt został podzielony na cztery główne podstrony, z których każda odpowiada za inny obszar mojej działalności:

*   `index.html` **(O mnie)** – Główne wprowadzenie, zdjęcie profilowe oraz szybkie odnośniki do pozostałych sekcji.
*   `doswiadczenie.html` **(Doświadczenie)** – Chronologiczny zapis mojej ścieżki zawodowej (m.in. data science w ERGO Hestia, optymalizacja procesów w marketingu i branży medycznej).
*   `samorzad.html` **(Samorząd)** – Przegląd inicjatyw i eventów edukacyjnych, które zorganizowałam jako Przewodnicząca Rady Samorządu Studentów WMFiI UG.
*   `projekty.html` **(Projekty)** – Moje portfolio analityczne (projekty z zakresu wizualizacji danych w Pythonie oraz uczenia maszynowego w R).
